# asheader - Simple wordpress shortcode plugin

## Overview
Created this plugin to provide a generic way to inject a _by line_ for all blog posts along with a last-updated timestamp.

## Usage
As a wordpress shortcode, add the following to your posts:

    [asheader name="Chris Baumbauer" url="/about/about-chris/"]
 
 * name - The name to user for the byline
 * url  - The URL to the about page for them

Will note this was written for me, but you could modify the PHP file to change out the name and URL so you would only need to pass the shortcode without specifying the parameters.
